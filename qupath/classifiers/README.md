# QuPath tissue pixel classifier

The original tissue pixel classifier used in the study is
[Class_Contour_GNT005.json](pixel_classifiers/Class_Contour_GNT005.json).

The classifier identifies the tissue region (`coupe`) in
the QuPath analysis script.

The original QuPath class definitions are also supplied
in [classes.json](classes.json).

## Installation

Copy `Class_Contour_GNT005.json` into the
`classifiers/pixel_classifiers/` directory of a QuPath project.

The classifier should be tested with QuPath 0.5.1,
the version reported in the manuscript.
